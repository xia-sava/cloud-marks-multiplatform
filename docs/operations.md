# 操作

データを変える操作と、その適用の規則。データの形と書き込みの手順は `docs/storage-format.md` にある。
フォルダをブラウザで開くような、データを変えない操作はここに含めない。

## 原則

- **操作は、目録を読み直した状態へ適用し直せる形で表す。** 書き込みが `412` などで失敗すると、読み直した状態へ同じ操作を
  適用し直す（`docs/storage-format.md` の「書き込みの手順」）
- **対象は ID で指す。** フォルダはフォルダの ID で、項目は項目を持つフォルダの ID と項目の ID の組で指す
- **操作が作るもの（フォルダ・項目）の ID は、操作を組み立てるときに振る。** 適用し直すときに振り直さない。
  適用し直すときにその ID が既にあれば、その部分は適用済みとして扱う
- **位置は「どの項目（フォルダ）の前か」で表す。** 目印を指さなければ末尾に置く。目印が無くなっていても末尾に置く
- **対象が無いとき、その部分は適用せずに利用者に伝える。** ただし削除は、対象がもう無ければ何もせず、伝えない
- 複数の操作を 1 回の書き込みにまとめてよい。まとめた操作は順に適用し、適用できなかった操作だけを飛ばして伝える
- アプリは、適用できなかったものを画面に出す。Native Messaging のホストは、拡張への応答として返す
- 根は、名前の変更・移動・削除ができない
- 入力が表の決まりに合わない操作（空の名前でフォルダを作る、名前を空にする、など）は適用しない

## 追加

### フォルダとして追加

複数の URL を、新しいフォルダにまとめて追加する。

| 入力 | 内容 |
|---|---|
| フォルダの ID | 新しく振る |
| 名前 | 空でない。利用者が入れる。既定は、追加した端末のローカル時刻で `YYYY-MM-DD HH:mm:ss`（例：`2026-11-16 21:30:15`） |
| 項目 | 項目の ID（新しく振る）・URL・タイトルの並び |
| 追加した日時 | 各項目の `added` になる |

- 根の子のフォルダの末尾に作り、項目を入力の順に入れる
- フォルダの ID が既にあれば、適用済み

### ブックマークとして追加

URL を、根の項目として追加する。

| 入力 | 内容 |
|---|---|
| 項目 | 項目の ID（新しく振る）・URL・タイトルの並び |
| 追加した日時 | 各項目の `added` になる |

- 根の項目の末尾に、入力の順に足す
- 根に同じ ID の項目が既にあれば、その項目は適用済み

## 項目

### 項目の削除

| 入力 | 内容 |
|---|---|
| 対象 | (フォルダの ID, 項目の ID) の組の並び |

- 対象を消す。もう無いものは何もしない

### 項目の挿入

消した直後に「元に戻す」で戻すときに使う。

| 入力 | 内容 |
|---|---|
| フォルダの ID | 入れる先 |
| 項目 | 項目の ID・URL・タイトル・追加した日時（あれば）の並び。消す前の値をそのまま使う |
| 位置 | どの項目の前か |

- 位置に入力の順に入れる。そのフォルダに同じ ID の項目が既にあれば、その項目は適用済み
- 入れる先のフォルダが無ければ、適用しない

### 項目の移動

| 入力 | 内容 |
|---|---|
| 対象 | 移す元の (フォルダの ID, 項目の ID) の組の並び |
| 移す先 | フォルダの ID |
| 位置 | 移す先の、どの項目の前か |

- 対象を元のフォルダから外し、移す先の位置へ入力の順に入れる。同じフォルダの中なら並べ替えになる
- 位置は対象を外したあとの並びで決める。目印が対象に含まれていれば末尾に置く
- 無い対象は飛ばす。移す先のフォルダが無ければ、操作全体を適用しない

### 項目のタイトルの変更

| 入力 | 内容 |
|---|---|
| 対象 | (フォルダの ID, 項目の ID) |
| タイトル | 空でもよい |

- 対象が無ければ、適用しない

## フォルダ

### フォルダの作成

| 入力 | 内容 |
|---|---|
| フォルダの ID | 新しく振る |
| 親 | フォルダの ID |
| 名前 | 空でない |
| 位置 | 親の子のフォルダのうち、どのフォルダの前か |

- フォルダの ID が既にあれば、適用済み
- 親が無ければ、適用しない

### フォルダの移動

| 入力 | 内容 |
|---|---|
| 対象 | フォルダの ID |
| 新しい親 | フォルダの ID |
| 位置 | 新しい親の子のフォルダのうち、どのフォルダの前か |

- 子孫ごと移す
- 対象か新しい親が無いとき、対象が根のとき、新しい親が対象そのものかその子孫のときは、適用しない

### フォルダの名前の変更

| 入力 | 内容 |
|---|---|
| 対象 | フォルダの ID |
| 名前 | 空でない |

- 対象が無いとき、根のときは、適用しない

### フォルダの削除

| 入力 | 内容 |
|---|---|
| 対象 | フォルダの ID |

- 子孫のフォルダと、それらの項目ごと消す
- 対象がもう無ければ何もしない。根は消せない
